# Basics and simulation of UNIX commands

Experiment 1a is a command-practice exercise (pwd, ls, cd, mkdir, rmdir, cat, cp, mv, ln, rm, who, date, echo, head, tail, wc, find, chmod, exit, clear, man, history, more, less). See the original manual in `../source_manual/OS_Lab_Manual.docx`.

The C simulations for `ls`, `cp`, `grep`, and `cat` are separate files in this folder.
